# Bugs

- **Technische Fehler:** `bugs.md`
- **Geräte-/Browserfehler und Cookies:** `bugs.md`; keine lokale Ursache oder
  Frist erfinden
- **App-/iOS-Probleme:** `bugs.md`; bei Einzelmeldungen keinen Incident ohne
  bestätigte Häufung eröffnen
- **Bekannter Fehler:** freigegebenes Bug-Makro und bestätigten Workaround
  verwenden
