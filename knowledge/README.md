# Ricardo-Wissensbasis

Die Wissensbasis ist nach den internen Prozessbereichen strukturiert:

- [Easy](easy/README.md)
- [Blockiert](blocked/README.md)
- [Kaufen / Verkaufen](buy-sell/README.md)
- [Gebühren](fees/README.md)
- [Bugs](bugs/README.md)

Querschnittsregeln stehen unter `_common/`. Historische Auswertungen stehen
unter `_historical/` und werden erst nach fachlicher Prüfung als verbindliche
Regeln übernommen.

Die vollständigen extrahierten E-Learning-Quellen liegen unter
`_sources/easygenerator/`. Sie dienen als Detailarchiv; aktuelle bestätigte
Regeln unter `_common/user-confirmed-rules.md` haben bei Widersprüchen Vorrang.

Die übergreifende Lern- und spätere Spezialagentenstruktur ist in
`docs/learning-roadmap.md` beschrieben. Neue Ticketstichproben werden über alle
Kategorien verteilt, damit keine einzelne Kategorie die Antworten verzerrt.
