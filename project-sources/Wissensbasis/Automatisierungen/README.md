# Automatisierungen

Automatisierte Zendesk-Abläufe müssen vor der Umsetzung eindeutig festlegen:

- Ziel und Auslöser
- betroffene Makros, Tickets oder Dynamic Content-Elemente
- Sichtbarkeit beziehungsweise Zielgruppe
- Abschlusscode
- Sprachvarianten
- notwendige Prüfung nach dem Speichern

Zugangsdaten, Passwörter, OTPs, Cookies und Session-Tokens werden nicht dokumentiert.
