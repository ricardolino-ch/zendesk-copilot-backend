# Antwortentwürfe

- Immer die gewünschte Sprache und die vier Varianten berücksichtigen.
- Standardbegrüssung: `Grüezi {{ticket.requester.name}}`
- Keine persönliche Anrede mit Herr oder Frau.
- Höflicher, klarer Schweizer Support-Ton.
- Links nicht unformatiert an einer beliebigen Stelle anhängen; sie gehören in den passenden Satz oder in einen eigenen Informationssatz.
